# Instrucoes Atuais - Riegos Dev

Atualizado em: 2026-05-06

## Direcao visual

Criar e manter um site profissional para a Riegos Dev com:

- light theme;
- superficies claras;
- ciano como assinatura visual;
- conteudo direto e facil de entender;
- imagens reais dos projetos;
- CTA forte para WhatsApp;
- layout responsivo.

## O que nao usar

- dark theme como base;
- particulas no hero, header ou background;
- typewriter no hero;
- glow pesado repetido;
- emojis como icones estruturais;
- copy longa demais em cards.

## Secoes esperadas

1. Header
2. Hero
3. Servicos
4. Processo
5. Portfolio
6. CTA final
7. Footer
8. WhatsApp FAB

## Requisitos

- Next.js App Router.
- Tailwind CSS v4 com tokens em `app/globals.css`.
- Conteudo centralizado em `lib/content/pt-BR.ts` e `lib/content/en.ts` quando possivel.
- Mobile-first.
- Contraste legivel.
- Botao de WhatsApp sempre facil de encontrar.
