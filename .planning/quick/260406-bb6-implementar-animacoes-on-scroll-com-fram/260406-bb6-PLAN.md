**AnimateOnScroll.tsx** — Create a reusable `'use client'` component using Framer Motion:

```tsx
'use client'
import { type ReactNode } from 'react'
import { motion, type Variants } from 'motion/react'

type AnimationType = 'fadeUp' | 'fadeIn' | 'staggerChildren'

interface AnimateOnScrollProps {
  children: ReactNode
  className?: string
  animation?: AnimationType
  delay?: number
  staggerDelay?: number
}
```

Define variants as constants outside the component:

- `fadeUpVariants`: container has `hidden: { opacity: 0, y: 28 }` and `visible: { opacity: 1, y: 0, transition: { duration: 0.7, ease: [0.16, 1, 0.3, 1] } }` (easeOutExpo cubic bezier)
- `fadeInVariants`: same but without y transform, duration 0.7
- `staggerContainerVariants`: `hidden: {}`, `visible: { transition: { staggerChildren: staggerDelay (default 0.09), delayChildren: delay } }`
- `staggerItemVariants`: `hidden: { opacity: 0, y: 24 }`, `visible: { opacity: 1, y: 0, transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1] } }`

The component renders a `motion.div` with:
- `initial="hidden"`
- `whileInView="visible"`
- `viewport={{ once: true, amount: 0.12 }}`
- The appropriate variants based on `animation` prop

For `staggerChildren` mode: the wrapper gets `staggerContainerVariants`, and each direct child must be wrapped in a `motion.div` with `staggerItemVariants`. Use `Children.map` + `motion.div` wrapping (same pattern as existing ScrollAnimations.tsx). This means consumers pass children directly and each child gets individually animated.

Export both `AnimateOnScroll` (named) and `staggerItemVariants` (for cases where consumers want to use motion.div directly).

**ProcessLine.tsx** — Create a `'use client'` SVG draw component using Framer Motion's `pathLength` animation:

```tsx
'use client'
import { motion, useInView } from 'motion/react'
import { useRef } from 'react'
```

- Render an SVG with the same layout as the existing static line: `className="absolute top-6 left-[12.5%] right-[12.5%] w-[75%] hidden md:block"`, `height="2"`, `viewBox="0 0 100 2"`, `preserveAspectRatio="none"`, `aria-hidden="true"`
- Use a `motion.path` element with `d="M0,1 L100,1"`, `stroke="rgba(0,255,255,0.35)"`, `strokeWidth="1"`, `fill="none"`, `strokeLinecap="round"`

- Animate `pathLength` from 0 to 1: `initial={{ pathLength: 0 }}`, `animate={isInView ? { pathLength: 1 } : { pathLength: 0 }}`, `transition={{ duration: 1.2, delay: 0.3, ease: "easeInOut" }}`
- Set `style={{ pathLength: 0 }}` as initial to prevent flash
