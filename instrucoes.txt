## ✨ REQUISITOS TÉCNICOS E VISUAIS

- **Animações de fundo:** partículas interativas ou ondas animadas em CSS — sutis, não distraem
- **Scroll suave** entre seções (smooth scroll)
- **Animações ao scroll** (Intersection Observer ou AOS.js): elementos entram com fade/slide
- **100% responsivo** — mobile-first
- **Performance:** imagens com lazy load, CSS minificado
- **Micro-interações:** botões com hover animado, cards com glow no hover
- **Fonte:** Inter ou Space Grotesk (Google Fonts)
- Todo o código em **um único arquivo index.html** (HTML + CSS inline + JS inline) para facilitar deploy imediato
